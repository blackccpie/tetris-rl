# AGENTS.md — Tetris-RL Project Conventions

## Project Overview
Toy/experimental Tetris RL using PyBoy (Game Boy emulator), Gymnasium, Stable-Baselines3, numpy, tqdm. Trains a PPO agent to play Tetris via the emulator screen observation.

## Key Design Decisions
- **Observation**: Compressed tile values (0–8) via `pyboy.game_area()` + `game_wrapper.mapping_compressed`, not binary. `18×10` board — `MlpPolicy` flattens, `CnnPolicy` uses `TetrisCNN` (`train.py:18` 3×3 small CNN, `normalize_images=False`) per 2024-25 Tetris RL (CNN>MLP, NatureCNN too large for 18×10).
- **Reward**: Hybrid PBRS `tetris_env.py:206` `score_delta + α*shaped_delta` where `shaped = get_total_score()` (`-0.5 height +0.75 lines -0.8 holes -0.35 bump` `tetris_env.py:245`, legacy `-0.35/-0.2` under-penalized holes → no rotation). `α=0.1` default (`--shaped-alpha 0.0` legacy pure score, sparse → plateau `Score 5-9`). Preserves optimal policy (Ng 1999).
- **Game over**: `pyboy.game_wrapper.game_over()`, not observation-based detection. Returns `-100 + α*shaped_delta`.
- **PyBoy `no_input=False`** — required for SDL2 window display on macOS (event queue must be pumped).
- **PyBoy speed**: `set_emulation_speed(0)` when `window="null"` (unlimited), `speedup` arg when `window="SDL2"`.

## Package Management
- `uv` — no `requirements.txt`; dependencies in `[project.dependencies]` in `pyproject.toml`.
- `uv sync` to install, `uv run` to execute.
- PyTorch: `torch>=2.2,<2.7` (`uv.lock` `2.6.0+cu124` pinned for GTX 960 sm_52; `2.7+` drops `sm_50` → `no kernel image` `sm_75+`). Maxwell GTX 960 sm_52 (2GB, driver 580) now GPU-enabled: `uv run train.py --device cuda --n-envs 4` → `297 fps` vs `95 fps` `n_envs 1` within `~400MiB`; modern GPU: `uv pip install --upgrade torch --index-url https://download.pytorch.org/whl/cu130` (use `uv run --no-sync` until lock bump). Former `<2.3.0` macOS 12 pin removed.
- Ubuntu 24.04: requires `libsdl2-2.0-0` at runtime (`sudo apt install libsdl2-2.0-0`); `libsdl2-dev` only to build PyBoy from sdist. With NVIDIA GPU <4GB VRAM use `--device cpu` unless legacy GPU path (see `train.py`). Large CUDA wheels (~2GB) — on slow link use CPU wheel: `uv pip install torch --index-url https://download.pytorch.org/whl/cpu` after `uv sync --no-install-package torch`.

## Entry Points
- `uv run train.py --device auto|cpu|cuda --window null|SDL2|headless --policy CnnPolicy|MlpPolicy --shaped-alpha 0.1 --sessions 200 --steps 2048 --freq 12` — default `CnnPolicy` `TetrisCNN` `α=0.1` `200×4×2048≈1.6M` (600≈5M 1200≈10M); `lr 1e-4 clip 0.1 ent 0.02 gamma 0.95 batch 32 freq 12` (ent 0.02 + `freq12` prevents rotation collapse); auto→`cpu` on <4GB VRAM or `sm_52` (`torch 2.6.0+cu124` pinned; `2.7+` ≥`sm_75`); then `--device cuda --n-envs 4` `~280fps cpu4→297 cuda4`; handles `Mlp→Cnn` and `7→6` (UP removal) incompatible saved models gracefully; ensures `models/` exists before save; `--tensorboard logs/` `--checkpoint-freq 10` (`0`=only end, `CTRL+C` saves) optional.
- `scripts/train_segments.sh --total 600 --per-segment 60 --n-envs 4` — Option A segmented resumable (10×500k for 5M), each `uv run train.py --sessions 60 --n-envs 4` resumes from `models/tetris_ppo_model.zip`; checkpoints `models/tetris_ppo_model_ckpt_*.zip` every `--checkpoint-freq`.
- `uv run play.py --rom/--init/--model/--window/--device/--deterministic --shaped-alpha 0.1 --freq 12` — must match train `α` and `freq`; SDL2 warns if no `DISPLAY`/`WAYLAND_DISPLAY` (use `xvfb-run -a`); `null`/`headless` for headless; `--no-deterministic` samples stochastically to see rotation at low `ent`.

## Key Files
- `tetris_env.py` — Gymnasium Env subclass; 6 actions (`LEFT/RIGHT/DOWN/A/B/PASS`, UP removed), observation (18,10) uint8, reward = hybrid `score + α*shaped` (`shaped_alpha`, `freq12`).
- `train.py` — PPO `TetrisCNN` (`CnnPolicy`) + `MlpPolicy` fallback, PBRS `α`, `SubprocVecEnv` optional.
- `agent_trainer.py` — simple training loop with tqdm.
- `states/init.state` — save state (PyBoy 2.7.0); regenerated by pressing START after ROM load.
- `roms/tetris.gb` — Tetris ROM (not tracked in git).
