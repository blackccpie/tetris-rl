# AGENTS.md — Tetris-RL Project Conventions

## Project Overview
Toy/experimental Tetris RL using PyBoy (Game Boy emulator), Gymnasium, Stable-Baselines3, numpy, tqdm. Trains a PPO agent to play Tetris via the emulator screen observation.

## Key Design Decisions
- **Observation**: Compressed tile values (0–8) via `pyboy.game_area()` + `game_wrapper.mapping_compressed`, not binary.
- **Reward**: Actual in-game score delta (`game_wrapper.score - previous_score`), not heuristic board features.
- **Game over**: `pyboy.game_wrapper.game_over()`, not observation-based detection.
- **PyBoy `no_input=False`** — required for SDL2 window display on macOS (event queue must be pumped).
- **PyBoy speed**: `set_emulation_speed(0)` when `window="null"` (unlimited), `speedup` arg when `window="SDL2"`.

## Package Management
- `uv` — no `requirements.txt`; dependencies in `[project.dependencies]` in `pyproject.toml`.
- `uv sync` to install, `uv run` to execute.
- PyTorch pinned `<2.3.0` (no wheel for macOS 12 x86_64 beyond that).

## Code Style (enforced by Ruff)
- Line length: 120
- Quotes: double
- Target: Python 3.12
- Ruff selects: `E, F, I, N, W, UP`
- Run: `ruff check . && ruff format --check .`

## Testing
- `uv run pytest tests/ -v`
- Fixtures: module-scoped `env` that creates a real `tetris_env` with `window="null"`.
- Test files: `tests/test_helpers.py` (pure-function tests), `tests/test_env.py` (Gymnasium API integration).

## Entry Points
- `uv run train.py` — trains PPO; handles incompatible saved models gracefully; saves to `--model-name`.
- `uv run play.py` — loads saved model and plays with SDL2 window.

## Key Files
- `tetris_env.py` — Gymnasium Env subclass; 7 actions, observation (18,10) uint8, reward = score delta.
- `agent_trainer.py` — simple training loop with tqdm.
- `states/init.state` — save state (PyBoy 2.7.0); regenerated by pressing START after ROM load.
- `roms/tetris.gb` — Tetris ROM (not tracked in git).
